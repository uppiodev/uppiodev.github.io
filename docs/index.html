Start with one prompt

Tell your agent:

Read https://api.madeyour.app/llms.txt and put this app on Uppio.

The agent documentation at https://api.madeyour.app/llms.txt is always current: the agent reads how to start an account, deploy, read logs and keep within the limits. It starts a free preview account with one request, with no sign-up and no personal data, and saves the account’s API key outside your repository.

A coding agent in a terminal works over the REST API at once. MCP clients get the same operations as tools; connect them with the account’s API key as below.

Connect over MCP

Replace <api_key> with the key your agent saved, and keep the key out of shared files.

Claude Code

claude mcp add --transport http uppio https://api.madeyour.app/mcp --header "Authorization: Bearer <api_key>"

The default local scope keeps the key out of the repository.

Cursor

In ~/.cursor/mcp.json, or .cursor/mcp.json of a project:

{
  "mcpServers": {
    "uppio": {
      "url": "https://api.madeyour.app/mcp",
      "headers": { "Authorization": "Bearer ${env:UPPIO_API_KEY}" }
    }
  }
}

Set UPPIO_API_KEY in your environment and restart Cursor.

Codex

In ~/.codex/config.toml:

[mcp_servers.uppio]
url = "https://api.madeyour.app/mcp"
bearer_token_env_var = "UPPIO_API_KEY"

Export UPPIO_API_KEY in the shell that starts Codex.

What your agent can do

  • Account and platform: the plan, limits and usage; the runtimes and their versions.
  • Apps: create one (static, PHP, Python or Node), list, inspect, delete.
  • Deploys: upload the project, deploy from a git repository, or write a few files straight from the chat; follow the build; roll back to the release before; download the code that is live.
  • Running apps: logs, commands in the app’s release, environment variables, restarts.
  • Databases: MariaDB databases, their address set for the app as DATABASE_URL.
  • Own domains: add a domain, see what its DNS shows, put its names on apps.

Keep your apps

A preview lives 72 hours. Your agent gives you a claim link: open it and confirm your email, and the account is yours. A claim starts a 14-day trial; with an invite code, the account moves to the beta plan.

Own domains

On a claimed account your agent adds your domain with add_domain, and you add two records at your domain’s DNS provider once:

  • *.example.com CNAME edge.madeyour.app, or that CNAME only for the names you want, like www;
  • _acme-challenge.example.com CNAME the address add_domain gives, which proves the domain is yours and renews its certificate.

Within minutes the domain has a certificate for itself and its subdomains. Then your agent puts names on apps with add_app_name: the domain itself or one level below it, like www.example.com. The domain itself can not have a CNAME: there use an ALIAS or ANAME to edge.madeyour.app where your DNS provider has one.

Good to know

  • Apps sleep after five minutes without requests and wake on the next one in a few seconds.
  • Server-sent events work; websockets do not yet.
  • Files your app writes while it runs (uploads, SQLite) belong in DATA_DIR: each deploy is a new release, and DATA_DIR outlives them.
  • The current runtimes, limits and rules are in the agent documentation.
